# 2.4.2 — release integration

Date: 2026-10-02

## Public release summary

2.4.2 makes it easier to get automations working. Set up with a goal adds a guided checklist, every automation gets a Before you start check, and event automations no longer need a preset made first. A castle's setup can also be copied to other castles.

It fixes attack counters, Auto Station's blocked warning and its Berimond reason, cooldown targeting in Auto Fortress and Auto Storm, the timed Run and Pause dialog, and notifications that disappeared too quickly.

Wording is plainer, dashboards are faster, use less data and resume after brief disconnects, and translations are extended.

Hosted players also get clear server-start statuses, a quicker return from offline, and Disable during server outages. The hosted log panel is removed.

## Desktop

### Added

- Set up with a goal walks you through a five-step checklist, from connecting to the game to the first result the game confirms, for goals such as playing the Khan event or keeping every castle fed.
- Each automation has a Before you start check that shows what is ready and what needs a change, and Start asks first when something would stop the automation from acting.
- Nomad, Samurai, Invasion, Khan, Storm and Beri World can set up their attacks right in their settings, without making a preset first, and show the troops and commanders each setup needs.
- Copy to other castles copies one castle's setup to the castles you pick, flags anything that can't be copied, and saves nothing until you press Save.
- The Settings language picker lists each language by its own name and adds an Automatic option that follows your device language without changing your game language.

### Fixed

- Attack counters start at zero, show whether they cover today or since a given time, label saved counts, and say when a count isn't available.
- Auto Station shows an amber warning instead of appearing armed when it can't protect a castle, and explains when Protection Mode or Berimond's lack of Open Gates is the reason.
- Auto Fortress and Auto Storm set aside a target the game reports as still cooling down and move on to others, and Auto Storm now reads fort cooldowns and hidden forts correctly.
- The timed Run and Pause dialog shows when the run or pause ends, in your language's date and time format, with correct plurals.
- Notifications stay on screen for at least 10 seconds and wait while you hover over or focus them.

### Changed

- Wording is plainer throughout: automations show Off instead of Disabled, event waits say when they resume, and commanders switched off for an automation show Off for this automation.
- Dashboards load faster, use less data, and pick up where they left off after a brief disconnect instead of reloading everything.
- The new setup screens are translated into German and Arabic, and every supported language gets more translated text; anything not yet translated appears in English.

## Portal

### Added

- Hosted accounts show "Starting a server for this account" or "Waiting for a free slot on our servers" while their server gets ready.

### Fixed

- An offline hosted dashboard switches back to live on its own within seconds once the account is running again.
- Disabling a hosted account is saved even while its server is unreachable, and the account stops as soon as the server is back.
- Opening a hosted account's saved data no longer crashes when that save has no castle information.
- English text on the public pages displays correctly when the site is shown in a right-to-left language such as Arabic.

### Changed

- Hosted accounts are placed on servers more reliably, and an account that moves to another server lets its running actions finish first.
- The cookie banner and privacy page now explain campaign measurement, which runs only if you allow analytics.

### Removed

- The log panel on hosted dashboards has been removed; attack-launch counts on the Automation page are unaffected.
