# 2.4.0 — pending release

This is a queued release item, not a declaration that 2.4.0 is published. Keep
the shipping version and 2.3.6 patch notes unchanged until the actual release.

## Fixed

- Duplicate alliance-help rejections (`AHR 273`, official
  `NO_MULTIPLE_ALLIANCEHELP`) no longer create an automation lane safety lock.
  The rejection remains visible as a failed operation; no new automatic retry
  is introduced. Whitelisted pairs also release any saved lane lock during
  startup refresh.
- Every non-whitelisted rejection, including CRA 256, MSD and unknown errors,
  locks only its originating lane for 30 minutes from the original rejection.
  Restarting does not reset the timer. Saved legacy locks are refreshed
  durably; expired locks become eligible again without manual approval.
